`src/thirdparty/sdsl_subset`.

- `tools/vendor_sdsl_subset.sh`

## Purpose of this subset
The retained files satisfy the currently used project sdsl surface:
- `sdsl::int_vector<>` / `sdsl::bit_vector`
- `sdsl::bits::hi`
- `sdsl::util::{expand_width,bit_compress,class_name}`
- `sdsl::{serialize,load}` and structure-tree helpers
- optional diagnostics (`size_in_bytes`, `write_structure`)

## Excluded categories
Not vendored:
- compressed text indexes (CSA/CST)
- wavelet trees
- rank/select compressed vectors (`rrr_vector`, `sd_vector`)
- coders (`elias_*`, `fibonacci`, etc.)
- LOUDS/BP/RMQ families
